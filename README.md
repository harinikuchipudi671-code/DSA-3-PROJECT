# DSA-3-PROJECT

Optimal Parenthesization and Output
Responsibility

Member 3 is responsible for determining and displaying the optimal parenthesization and final results.

Tasks Completed
Created the split table.
Stored the optimal split position for each subproblem.
Reconstructed the optimal parenthesization.
Displayed the minimum multiplication cost.
Displayed the optimal multiplication order.
Displayed intermediate results such as cost and split tables where applicable.
Concepts Covered
Optimal parenthesization
Split table
Recursive reconstruction
Minimum multiplication cost
Result interpretation
Example

For matrices A1, A2 and A3, the program compares:

(A1 × A2) × A3

and

A1 × (A2 × A3)

The split table helps identify which parenthesization produces the minimum cost.

Contribution

This module converts the results of the Dynamic Programming algorithm into an understandable final solution by displaying the optimal multiplication order and its minimum scalar multiplication cost.
