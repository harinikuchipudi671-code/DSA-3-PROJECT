# Member 1 README — Algorithm and Input Processing

## Project Title
Matrix Chain Multiplication Optimization Tool

## Contribution
My contribution to this project focuses on understanding the Matrix Chain Multiplication problem, implementing the algorithmic logic, and handling matrix dimension inputs.

### 1. Problem Understanding
Matrix Chain Multiplication is an optimization problem in which the goal is to find the best order for multiplying a sequence of matrices while minimizing the number of scalar multiplications.

### 2. Algorithm Concepts
- Studied Dynamic Programming and its application to Matrix Chain Multiplication.
- Understood the optimal substructure property and overlapping subproblems.
- Worked with matrix dimensions and scalar multiplication cost.
- Studied the recurrence relation used to calculate the minimum cost.
- Helped explain the optimal parenthesization of matrices.
